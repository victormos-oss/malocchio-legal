# Malocchio: правовые страницы

Публичный адрес для документов приложения Malocchio. Здесь лежит только то, что
должно быть доступно по ссылке из App Store Connect, поэтому репозиторий
открытый, а код приложения остаётся закрытым.

- `index.html`, `privacy.html` — политика конфиденциальности на русском,
  английском и испанском. Язык переключается на самой странице, адрес один.

Публикуется через GitHub Pages: https://victormos-oss.github.io/malocchio-legal/

Правки вносить в `malocchio/legal/privacy.html` в основном репозитории и
копировать сюда, чтобы две версии не разъехались.
